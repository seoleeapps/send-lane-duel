## 아트 방향

세계관은 태엽 장난감으로 확정했다(DEC-004). 같은 세계관 안의 시각 방향은 사용자 선택으로 정한다. 같은 대표 화면(SCR-003 원정, 배분 중)을 기준으로 세 안을 비교한다. 판타지 종족 군대와 SF 군대는 블리자드 작품을 떠올리게 하므로 후보에서 뺐다(`../policy-review.md`).

| 항목 | A 태엽 장난감 | B 버섯 숲 정령 | C 해저 산호 왕국 |
| --- | --- | --- | --- |
| 한 줄 | 장난감 상자 속 태엽 병정들이 서로의 선반으로 장난감을 보낸다 | 숲의 버섯 정령 부족이 포자 무리를 보내 겨룬다 | 산호초를 지키며 물고기 떼를 보내는 왕국들 |
| 레인 | 나무 선반 위 철길 | 이끼 낀 통나무 길 | 물살이 흐르는 해류 길 |
| 성 | 장난감 성곽 블록 | 큰 그루터기 | 산호 궁전 |
| 금화·일꾼 | 단추 · 태엽 감는 생쥐 | 도토리 · 개미 | 진주 · 소라게 |
| 방어 4계열 | 새총 병정, 대포 장난감, 목마 기병, 요술 상자 | 가시 궁수, 포자 주머니, 사슴벌레, 반딧불 무당 | 가시고기, 복어, 황새치, 해파리 |
| 용병 무리·정예 | 구슬 떼 · 곰 인형 | 포자 떼 · 두꺼비 | 정어리 떼 · 거북 |
| 지휘관 6 | 장난감 대장 6종 | 숲의 족장 6종 | 바다 영주 6종 |
| 장점 | 연령 폭이 넓고 형태가 단순해 생성 일관성이 높다. "보내기"가 장난처럼 읽혀 폭력 수위가 낮다 | 속성 8종을 색과 형태로 나누기 쉽다 | 흐르는 레인 표현이 자연스럽다 |
| 약점 | 유아용으로 보이면 스토어에서 아동 대상으로 오해받을 수 있다(POL-003) | 어두운 숲 배경에서 작은 유닛 가독성 | 푸른 계열에 색이 몰려 속성 구분이 어렵다 |
| 생성 난이도 | 낮음 | 중간 | 중간 |

추천은 A 다. 이유는 가독성과 생성 일관성, 낮은 폭력 수위다. 단 스토어 그림은 전략 게임으로 읽히게 구성해야 한다. 최종 선택은 시안 이미지를 본 뒤에 한다.

화풍은 세 안 모두 **굵은 외곽선의 플랫 카툰**을 기본으로 한다. 사내 생성 파이프라인에서 일관성이 가장 좋은 범위다.

## 시각 문법

| 대상 | 규칙 |
| --- | --- |
| 속성 8종 | 색 + 모양 + 기호 세 겹(`03-ui-ux-spec.md` 디자인 시스템). 유닛과 적의 발밑 받침에 같은 기호를 넣는다 |
| 내 것과 지휘관 것 | 내 것은 따뜻한 테두리, 지휘관 것은 차가운 테두리. 방향도 다르다(내 용병은 위로, 적은 아래로) |
| 단계 1·2·3 | 받침 아래 점 1·2·3개 + 크기 100/112/125% |
| 무리와 정예 | 무리는 작은 개체 여러 마리, 정예는 큰 개체 하나. 실루엣만으로 구분 |
| 숨은 정보 | 지휘관이 보낼 용병은 물음표 주머니. 공개될 때 뒤집힌다 |
| 지휘관 성향 | 초상 옆 아이콘 하나(방패, 돌진 화살, 저금통, 주사위, 반격 화살, 과녁) |

## 캐릭터와 세계

- 지휘관 6명은 성향이 얼굴과 소품으로 읽혀야 한다. 철벽은 두꺼운 갑옷, 욕심은 큰 자루 같은 식이다.
- 이야기 글은 없다. 지휘관마다 등장 한 줄, 패배 한 줄만 둔다(문자열 표로 분리).
- 세계관이 바뀌어도 id 는 그대로다. 표시 이름은 `data/content/*.json` 의 `name_ko`, `name_en` 만 바꾼다.

## UI 아트 경계

- 글자, 수치, 배치, 입력은 엔진이 처리한다. 이미지에 글자를 굽지 않는다.
- 버튼·패널은 9분할 이미지로 만든다. 분할 경계와 안쪽 여백을 에셋 목록에 적는다.
- 상태가 있는 이미지(기본·눌림·비활성)는 같은 캔버스, 같은 좌표로 만든다.
- 유닛과 적은 투명 배경 PNG, 받침과 기호는 엔진에서 겹친다.

## VFX 언어

- 타격: 속성 기호가 튀는 짧은 조각. 강한 상성은 크고 밝게, 약한 상성은 작고 흐리게.
- 누수: 적이 성으로 돌진하고 성 체력 막대가 그 자리에서 깎인다. 화면 흔들림은 쓰지 않는다.
- 금화: 정산 때 동전이 수입 숫자로 날아든다.
- 모든 효과는 박자 길이(0.35초) 안에 끝난다. 움직임 줄이기에서는 숫자와 막대 변화만 남긴다.

전투 박자와 원정 배경음의 박자를 맞춘다(박자 0.35초 ≈ 분당 171박의 절반인 86박 기준). `game-sound-pipeline` 으로 만들고 들어 본 뒤에만 채택한다.

## 생성과 라이선스

- 그림은 `game-asset-pipeline`, 소리는 `game-sound-pipeline` 으로 만든다. 에셋마다 도구·모델, 프롬프트, 참조 그림, 수정 이력, 마켓 사용 가능 여부를 생성 기록에 남긴다.
- 경쟁작과 원작의 화면, 아이콘, 유닛 그림을 참조 그림으로 쓰지 않는다.
- 글꼴은 재배포 가능한 라이선스(OFL 등)만 쓴다. 한국어와 영어를 한 글꼴 가족으로 맞춘다.
- 시안 프롬프트 뼈대(세 안 공통): "세로 모바일 게임 화면, 굵은 외곽선 플랫 카툰, 위에 상대 진영 6칸, 가운데 두 줄 레인, 아래 내 진영 6칸과 세 칸 조작 패널, 글자 없음" + 세계관 문장.
