## 스토어와 정책

- 제출 전 `apple-app-store-registration` 의 문구·이미지 검수 절차와 `google-play-publishing` 을 따른다. 활성 언어 전부의 제목·부제·소개·키워드·캡처를 검수한다.
- App Store 의 문구·이미지·앱 화면에 다른 모바일 플랫폼 이름을 넣지 않는다(POL-028).
- 원작 유즈맵, 블리자드 작품, 다른 게임의 이름을 문구와 키워드에 쓰지 않는다(POL-029, `../policy-review.md`).
- 보상형 광고는 버튼에 보상 내용을 적고 사용자가 누른 뒤에만 재생한다(POL-001, POL-040).
- 전면 광고는 예상할 수 있는 전환 지점에서만 낸다. 앱 실행 직후, 판 도중, 화면을 떠날 때 갑자기 내지 않는다(POL-001).
- Android targetSdk 36, 16KB 페이지 대응을 빌드 검사에 넣는다(POL-007, POL-008).

## 출시 포지셔닝과 획득

- 한 문장: "힘을 팔지 않는 한 손 디펜스. 지키고, 키우고, 보내라."
- 광고가 있는 무료 게임이고 결제는 없다. 스토어 문구에서 "광고 없음"을 말하지 않는다. "앱 내 구매 없음"은 사실이므로 써도 된다.
- 스토어 첫 캡처는 SCR-003 의 세 갈래 배분과 "지휘관의 용병이 공개되는 순간"이다.
- 차별 문구 세 개: 앱 내 구매 없음, 오프라인에서 끝까지, 매일 모두 같은 조건의 도전.
- 유입은 유료 광고를 전제하지 않는다(`00-product-brief.md` A-04). 소프트론칭에서 스토어 검색 유입과 일일 도전 점수 공유 그림(텍스트 없는 결과 카드)의 효과를 본다.
- 타깃 확정(DEC-002) 뒤 문구와 캡처를 다시 쓴다.

## 현지화와 고객지원

- 출시 언어: 영어, 한국어. 문자열 키는 처음부터 분리하고 지휘관 대사·증표 설명은 번역 표로 관리한다.
- 숫자와 기호로 전달하는 비율을 높여 번역량을 줄인다. 번역 뒤 최소 화면에서 넘침을 확인한다.
- 지원: 설정 안 "문의" 메일 링크(기기·버전·사용자 id 자동 첨부), 자주 묻는 질문 5개(저장, 광고가 안 나올 때, 순위 기록, 데이터 삭제, 오프라인).

## 롤백과 운영

- 광고: 배치마다 원격 끄기 스위치가 있다(`bm-profile.json` 의 `*_enabled`). 문제가 생기면 먼저 끈다.
- 난이도: 원격 설정으로 되돌린다. 일일 도전에는 적용되지 않으므로 그날의 공정성은 유지된다.
- 순위표 조작: 해당 기록 삭제, 필요하면 그날 순위표 숨김.
- 치명적 오류: 스토어 단계적 출시를 멈추고 직전 버전으로 되돌린다. 저장 형식을 올린 버전은 되돌리기 전에 이전 버전이 새 저장을 읽을 수 있는지 확인한다.
- 운영 점검: 주 1회 Crashlytics 와 지표 확인. `launched-game-metric-issues` 흐름에 등록한다.
