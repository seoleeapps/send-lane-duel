- 상태: 승인
- 근거: 2026-10-06 사용자 객관식 결정 및 `Implement the plan.` 요청
- 이름: Three Purses
- 작업 ID / 저장소: send-lane-duel / seoleeapps/send-lane-duel (비공개)
- Android / iOS: com.seoleeapps.sendlaneduel
- Play 계정: Seolee Apps / wellknowngeek@gmail.com. 계정별 테스트 요건은 콘솔 확인 전 미확인.
- 플랫폼 / 언어: Android·iOS / 영어·한국어
- 타깃 / 소프트론칭: 전략 캐주얼 경험 20~40대 / 캐나다·호주·한국
- 세계관: 태엽 장난감. 대표 화면 시각 방향 A/B 선택은 별도 기록한다.
- 수익화: AdMob·Poing, 전면·보상형만. 전면 5초 닫기 기준 유지, 고참여 광고·외부 입찰 제외. 확인 전 활성화하지 않는다.
- 순위표: 하루 1회 상위 100개를 Python 참조 코어로 재생 검수. 순위 보상 없음.
- Firebase: 앱 전용 프로젝트 생성 승인. 과금 연결·유료 요금제·스토어 제출·공개 출시 승인 없음.

## 제작 순서

정수 코어 및 벡터 100건 → 회색 상자 한 런·저장·복귀 → 사람 5명 테스트 → 선택한 시각 방향의 첫 세션 → 전체 콘텐츠·온라인·광고 → 실기기·출시 후보.

Core 단계에서 사람 테스트가 끝나기 전 다음 단계 완료를 주장하거나 밸런스를 임의로 변경하지 않는다.

## 구현으로 확인된 보정

- Python 참조의 잘못된 행동은 진영을 바꾼 후 예외를 내는 경우가 있다. 구현에서는 행동 전체를 복사한 진영에 검증하고, 성공한 경우에만 적용한다. 정상 행동 벡터는 변경하지 않는다.
- Python 도구를 `tools/sim/`으로 이동했으므로 데이터 기준 경로를 저장소 루트로 수정했다.
- 전면 최소 플레이 3분을 기존 문서에서 수익화 프로필의 `remote_config.interstitial_min_play_seconds`로 반영한다. 원격 설정은 승인된 상한을 완화하지 못한다.
