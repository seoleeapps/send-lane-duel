# Three Purses

태엽 장난감의 성을 지키며 금화를 병사·일꾼·공격 병력에 나누는 세로형 로그라이크 디펜스.

- Android / iOS, 영어 / 한국어. Godot 4.7.2, 패키지 `com.seoleeapps.sendlaneduel`.
- 첫 시작에 직접 조작하는 3턴 연습이 열린다. 건너뛰기·중단 후 복귀·설정에서 다시 배우기를 지원한다.
- 4장 원정, 길과 보상 선택, 편성 해금, 격, 오프라인 일일 도전. 장난감 아트·전투 재생·음악과 효과음 적용.

실행: `godot --path .` · 검사: `bash scripts/check.sh`

Android 개발용 빌드: `build/android/three-purses-playable.apk` — 0.1.1/2, ARM64 디버그 APK.

[제작·검증 상태](docs/07-qa/implementation-status.md), [실행 화면 비교](docs/07-qa/playable-visual-review.md), [기획 원장](docs/01-planning/), [사람 테스트 양식](docs/07-qa/core-playtest.md).

현재 로컬 플레이 빌드다. 사람 재미 검증, 실제 휴대폰·iPhone 검증, 온라인 서비스·광고 SDK·심사·출시는 남아 있다.
